# JustTheFood — Home Assistant Add-on Repository

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FD3L05%2Fhomeassistant-justthefood)

Home Assistant add-on repository for **JustTheFood** — a recipe manager with cooking mode, smart timers, and HA integration.

## Add-ons

### [JustTheFood](./justthefood)

![JustTheFood](./justthefood/icon.png)

Paste any recipe URL → get a clean recipe → cook step-by-step with timers.

- Extract recipes from any website (AI-powered optional)
- Cooking mode with progress tracking
- Smart timers that integrate with Home Assistant
- Personal cookbook with saved recipes

## Installation

1. Click the badge above to add this repository
2. Find **JustTheFood** in the Add-on Store
3. Install & start — access via sidebar
