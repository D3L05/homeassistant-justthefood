# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-02-14

### Added
- AI-powered recipe extraction (OpenAI, Gemini, Claude)
- Configurable AI provider and model settings
- Home Assistant timer integration with entity selection
- TTS announcements for timer events
- Notification service support

### Fixed
- Timer authentication with Supervisor API
- Ingress path handling for CSS and static assets
- HTML entity decoding in recipe text

## [1.0.0] - 2026-02-07

### Added
- Recipe extraction from any URL
- Cook mode with step-by-step instructions
- Built-in countdown timers with audio alerts
- Recipe saving and personal cookbook
- Home Assistant ingress integration
- Responsive mobile-friendly design
